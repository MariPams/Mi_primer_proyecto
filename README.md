# Mi primer proyecto Python

Este repositorio ha sido creado como parte de mi formación en Python en Tokio School.

El objetivo del proyecto es aprender a utilizar Git y GitHub para gestionar el control de versiones de un proyecto.

## Contenido del proyecto

Este proyecto también servirá para practicar el flujo básico de trabajo con Git: realizar cambios, preparar archivos y registrar nuevas versiones mediante commits.
